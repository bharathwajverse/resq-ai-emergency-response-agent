# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [1.0.0] - 2026-10-04

### Added

- **AI Agent Orchestrator** — Multi-step reasoning pipeline with replanning
- **Search Algorithms** — UCS, DLS, IDS, A*, Best First, Hill Climbing, Beam Search
- **Constraint Satisfaction** — CSP with backtracking and constraint propagation
- **Inference Engine** — Forward chaining, backward chaining, and resolution
- **Bayesian Risk Analysis** — Probabilistic risk assessment
- **Decision Tree Learning** — scikit-learn based priority prediction
- **Planning System** — State-space, partial-order, and hierarchical planning
- **Knowledge Base** — Frames, ontology, and relationship modeling
- **LLM Service** — Gemini API integration with demo mode fallback
- **Frontend Dashboard** — 10-page React application with Tailwind CSS
- **REST API** — Full FastAPI backend with Pydantic validation
- **Database** — PostgreSQL/SQLite with 9 tables and seed data
- **AI Algorithms Lab** — Interactive educational algorithm explorer
- **Testing** — Unit, integration, and E2E test suites
- **Documentation** — README, Architecture, Algorithms, FAI Mapping, API, Database, Testing, Viva
- **5 Demo Scenarios** — Road accident, fire, flood, medical emergency, multi-incident
